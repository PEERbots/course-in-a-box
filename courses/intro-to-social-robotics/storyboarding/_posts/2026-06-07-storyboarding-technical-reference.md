# Robot Interaction Storyboarding Technical Reference Materials

This page contains the key concepts and references on interaction storyboarding. Use this as a reference or read it to learn more about industry best practices.

## Background Information & Relevant Research

{% include definition.html term="Branching Narrative" definition="A story structure that splits into multiple distinct paths depending on the user's choices or inputs, allowing a robot to handle different conversational directions." %}
{% include definition.html term="Big Picture Storyboarding" definition="An approach focusing on high-level interaction concepts (similar to drawing with a thick marker) rather than details, ensuring developers align on goals early in the design phase." %}
